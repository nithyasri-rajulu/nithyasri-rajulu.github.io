# Nithyasri Rajulu — Engineering Portfolio

Personal portfolio covering robotics, mechatronics, industrial control and computer vision, with a CV and engineering reports. Thesis start: Spring 2027.

## Publish this portfolio with GitHub Pages

You do not need to buy a domain. This package is prepared for the GitHub account `nithyasri-rajulu` and the free address:

**https://nithyasri-rajulu.github.io/**

That address becomes available only after you complete the steps below. This ZIP does not create a repository or publish the website automatically.

1. Download and extract the ZIP on your computer. Open the extracted folder: you should see `index.html`, `styles.css`, `app.js`, `assets`, and `projects`.
2. Sign in to GitHub as **nithyasri-rajulu**. Click the **+** menu, then **New repository**.
3. Enter **nithyasri-rajulu.github.io** as the repository name, choose **Public**, turn on **Add README**, and click **Create repository**. If this repository already exists, open it instead; keep a copy of any existing website before replacing its files.
4. On the repository's **Code** tab, select **Add file → Upload files**. Drag the extracted folder's **contents** into the upload area, including the complete `assets` and `projects` folders. Upload the files, not the ZIP or its outer folder. `index.html` must appear directly on the repository's Code page, beside `assets` and `projects`.
5. Click **Commit changes**, using the `main` branch. If GitHub asks for a message, use `Add my engineering portfolio`.
6. The package includes `.nojekyll`. If your computer hides it and it was not uploaded, select **Add file → Create new file**, name the file **.nojekyll**, enter `Static portfolio`, and commit it to `main`.
7. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**. Choose **main** and **/(root)**, then click **Save**. Leave **Custom domain** empty.
8. Allow up to 10 minutes. Return to **Settings → Pages** and click **Visit site** when GitHub shows the published address.
9. Open the portfolio on your phone and computer. Check a project, the CV download and the contact links. Then use **https://nithyasri-rajulu.github.io/** on your resume and thesis applications.

No terminal, installation or paid hosting is required. Your website files will be publicly visible in this public repository.

## If something does not work

- **404 page:** check that the repository name matches your GitHub username exactly, that it is public, and that Pages uses `main` and `/(root)`. Ensure `index.html` is at the repository root. Wait for the Pages deployment to finish.
- **Missing images or styling:** upload the complete `assets` and `projects` folders, plus `styles.css` and `app.js`, preserving names and folders.
- **Pages has no branch to select:** finish committing the upload, refresh Settings, and try again.
- **Updating later:** upload changed files to the same paths and commit them. Pages republishes from `main` automatically.

The portfolio and CV PDFs in this package point to the GitHub Pages address above. Publish the website before distributing those copies.
